03

Stage Wand

Your phone, as a presenter remote and trackpad.

Volume buttons move slides. Unlock the square for pointer, click, and scroll on a Mac, Windows, or Linux host.

  • Mac, Windows, Linux host
  • iPhone, Android remote
  • Open source

Download for Mac → Source on GitHub

04

Snippets

Saved snippets, one Hyper key away.

A macOS menu bar app. Press Hyper (caps lock) + a key to paste text, rich text, or images into any field. Several snippets on one key get a numbered picker, and your clipboard is restored after every paste. Open source, auto-updates.

  • macOS 26+
  • Menu bar
  • Open source

Download for Mac → Source on GitHub
